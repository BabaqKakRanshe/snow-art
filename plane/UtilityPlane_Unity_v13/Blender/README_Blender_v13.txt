Utility Plane v13 — файлы Blender (огни как часть самолёта, сдвижные грузовые двери)

Открывать в Blender 5.0 или новее (сохранены в 5.0.1). Текстуры подключены относительными путями и берутся из пакета рядом (..\Assets\UtilityPlane\Textures), зимний комплект — из ..\..\UtilityPlane_WinterKit_v1_2\Assets\UtilityPlane\Textures. Если файл открыт из другой папки: File → External Data → Find Missing Files.

- UtilityPlane_v13.blend — модель v13; Models/UtilityPlane.fbx выгружен из той же геометрии. Сцена v12: самолёт, зимний комплект 1.2, отдельные модели (ящики, стремянка, ключ, аварийный комплект).
- UtilityPlane_v13_lights.blend — та же модель со светом для Cycles: IES-профили и функции света, туман, камеры (описание — текст README_v13_lights внутри файла и README_IES.txt в папке IES).

Что изменилось с v12:
- Огни — часть самолёта: в Body добавлены корпуса огней (обтекатель законцовки киля с фланцем верхнего маяка, накладка днища с фланцем нижнего маяка, корпуса на законцовках крыла, бобышка хвостового огня, рамка колпака фары по передней кромке). Линзы Lens_* новые, с UV в текстуру T_Lens; восемь сокетов наружных огней и origin линз — в новых корпусах. Подробности — UNITY_CONTRACT.md, раздел 7.8.
- Материалы линз M_Light_Red / Green / White / Beacon / Landing: цвет = T_Lens_BaseColor × цвет линзы, свечение = T_Lens_Emission × цвет свечения, текстуры по точкам (Closest).
- Сдвижные грузовые двери: в Body — направляющие (над проёмом, под порогом, на борту за проёмом), у CargoDoor_L/R — три ролика на кронштейнах. Посмотреть ход: выделить корень UtilityPlane, панель N → Item → Properties → cargoDoorL / cargoDoorR от 0 до 1 (0 — закрыта, 0.25 — вышла наружу, 1 — сдвинута назад). Двери двигают драйверы с простыми выражениями — запускать скрипты Python не нужно; промежуточные значения считают пустышки CargoDoor_L_Ctl / CargoDoor_R_Ctl в коллекции «v13 door drivers» (скрыты). Формула — та же, что UtilityPlaneRig.SlidingDoorPose (UNITY_CONTRACT.md, раздел 3.1). Перед выгрузкой FBX поставить cargoDoorL и cargoDoorR в 0.
- В файле со светом: источники огней сидят на новых сокетах (дети сокетов); Light_Beacon_Top снова точно на сокете (в v12 был поднят на 3 см внутрь старого колпака); каждый наружный огонь не затеняется своей линзой (навигационные огни и стробы — ещё и второй линзой корпуса законцовки и, как раньше, Body).
- Остальное — как в v12.
