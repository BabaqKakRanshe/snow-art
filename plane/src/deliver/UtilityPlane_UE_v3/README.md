# Utility Plane для UE5.6 (v3)

STOL-турбопроп для симулятора от первого лица: внешний меш и кабина. Оба меша — skeletal с жёсткой сегментацией, PBR-атласы, скрипт импорта.

## Состав

| Файл | Что это |
|---|---|
| `SK_UtilityPlane.fbx` | экстерьер: фюзеляж, крыло, оперение, рули, двери, шасси, винт, огни и сокеты |
| `SK_UtilityPlane_Cockpit.fbx` | кабина: приборы, органы управления, кресла, обшивка салона |
| `Textures/` | атласы Airframe 4K, Cockpit 4K и Details 2K (BC / N / ORM), T_Gauges_BC 4096×2048, T_CargoNet_BCA |
| `ue_import_utility_plane.py` | импорт в `/Game/Vehicles/UtilityPlane`: текстуры, материалы, инстансы, слоты |
| `ANIM_CONTRACT.md` | кости, оси, знаки и диапазоны, формулы стрелок, таблица слотов |
| `rig.json` | позиции всех костей и сокетов (см, кадр UE) |
| `Blender/UtilityPlane_v3.blend` | исходник с теми же текстурами (Cycles-превью) |
| `Renders/` | контрольные рендеры |

Архив разбит на части, потому что файлы больше 30 МБ не передаются. Все zip распаковывай в одну папку.

## Быстрый старт

1. Распакуй все части в одну папку, например `D:/UtilityPlane_UE_v3`.
2. В проекте UE5.6 включи плагин **Python Editor Script Plugin** и перезапусти редактор.
3. Запусти скрипт: Tools → Execute Python Script → `ue_import_utility_plane.py`.
4. Оба меша поставь в один Blueprint: `SK_UtilityPlane` корнем, `SK_UtilityPlane_Cockpit` дочерним, трансформ нулевой.
5. Камеру пилота привяжи к сокету `Socket_PilotEye`.

## Текстуры

- `T_*_BC` — base color, sRGB.
- `T_*_N` — нормали, DirectX (G уже инвертирован). Запекались в MikkTSpace, поэтому в UE тоже MikkTSpace.
- `T_*_ORM` — R = AO, G = Roughness, B = Metallic, линейная.

AO запекался с разным радиусом: снаружи 0.6 м, в кабине 0.22 м. С большим радиусом закрытая кабина получилась бы чёрной. UV-раскладка без перекрытий, отступ между островами 8 px.

## Ограничения

- В самом UE я это не запускал, в среде сборки движка нет. Скрипт написан по Python API 5.x, опасные места обёрнуты `try_set` и пишут предупреждения в Output Log. Если импорт FBX через Interchange поведёт себя иначе, настройки для ручного импорта есть в `ANIM_CONTRACT.md`.
- Physics Asset и LOD не создаются, рекомендации в `ANIM_CONTRACT.md`.
